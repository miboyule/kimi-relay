First desktop preview based on MIT-licensed Kimi Work Gateway 0.9.0. Bundles its own Node runtime, first-run setup, tray lifecycle, isolated state, backups and fixed-proxy migration.

**Third-party API top-ups do not add official Kimi credits.** Use your own model provider inside Kimi Work; official account and service requirements remain unchanged.

Extract the matching ZIP completely and launch the app. Closing the window hides it to the tray. Domain-resolution changes require explicit opt-in. Publisher signing and Apple notarization are not configured. See the bilingual README and recovery guide; verify downloads with SHA256SUMS.

The Kimi 3.2.27 Windows parser accepted all five sample models. Local synthetic tests cover HTTP, SSE, Responses, migration and authentication. Platform build and packaged desktop smoke tests gate release assets. These checks do not replace a signed-in real-provider inference test.
